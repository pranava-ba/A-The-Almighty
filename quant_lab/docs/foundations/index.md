# Foundations

A short, math-light on-ramp to the ideas the rest of the site assumes. If you've never
priced an option or read a Sharpe ratio, start here — each page is one idea, in plain
English first, with the formal version beside it for those who want it.

The throughline of the whole portfolio is **honesty about luck**: financial data is short
and noisy, so it is very easy to find a strategy that looks brilliant on the past and is
worthless on the future. Most of the machinery here exists to tell the two apart.
